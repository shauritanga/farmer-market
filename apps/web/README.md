# Fama — Admin Dashboard

React + TypeScript admin/operations dashboard. Part of the `farmer-market` monorepo —
see the root `README.md` and `AGENTS.md`, and this folder's `CLAUDE.md` for
stack-specific rules.

## Getting started

```bash
# from the repo root
npm run dev:web        # http://localhost:5173
```

## Validation

```bash
npm run build --workspace apps/web
npm run lint --workspace apps/web
```
